# PixVault 功能路线建议

## 第一优先级：把已有能力做完整

1. **后台导入与索引**：使用 WorkManager 展示进度、支持取消和断点恢复，解决大量照片导入时离开页面即中断的问题。
2. **相似/重复照片清理页**：现有哈希可拦截完全重复文件；下一步增加感知相似分组、左右对比和“一键保留最佳”。
3. **首次启动指引（已完成）**：三页解释“照片复制入库”“AI 全程本地运行”“删除与回收站规则”，并可从设置页重复打开。
4. **EXIF 保真**：导入与编辑后保留拍摄时间、方向等核心元数据，避免时间线错乱。

## 第二优先级：强化本地 AI 差异化

1. **智能相册**：把自然语言搜索条件保存为动态相册，例如“猫 + 夜景 + 收藏”。
2. **本地 OCR 搜索**：离线提取截图、票据和海报文字，与现有语义搜索合并展示。
3. **更好的标签学习**：标签支持正例与反例，展示置信度，并允许批量确认 AI 建议。
4. **以图搜图入口**：从分享菜单或详情页选一张图片，直接寻找视觉近似图片。

## 第三优先级：提升日常图库体验

1. 按年月时间线、拍摄地点地图与“回忆”卡片。
2. Android 分享目标与相机快捷导入。
3. 私密空间：生物识别锁；若定位为真正的 Vault，再增加文件加密与锁屏预览保护。
4. 导出/迁移：选定相册打包导出，并提供数据库与原图一致性检查。

## 推荐下一轮

优先实现“后台导入进度 + 相似照片清理页”。首次启动指引已经落地，下一步重点解决大图库稳定性和重复照片整理效率。
