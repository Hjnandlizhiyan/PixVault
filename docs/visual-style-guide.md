# PixVault 视觉资源指南

## 方向

- 关键词：二次元、简洁、安心、本地、轻盈。
- 主色：紫罗兰 `#6650A4`、长春花蓝 `#7C83FD`、浅蓝 `#DCE7FF`。
- 点缀：淡粉 `#EFB8C8`；线稿与深色面使用深靛 `#25233A`。
- 角色：短靛蓝发的“档案管理员”，淡紫色连帽衫；角色只负责传递情绪，不遮挡功能信息。
- 插画不嵌入文字，文案统一由 Compose 渲染，便于本地化与无障碍适配。

## 生成说明

三张资源均使用图像生成模式创建：空状态和新手指引采用 `illustration-story`，图标采用 `logo-brand`。提示词约束了统一角色、配色、无文字、无水印和 Android 使用场景；透明资源保留 Alpha 通道。

## UI 使用原则

- 空状态插画建议宽度 180–240dp，正文放在图片下方。
- 同一页面只出现一张角色插画，避免图库内容被抢走视觉焦点。
- 通用角色目前覆盖图库、搜索、收藏、标签文件夹、回收站与相似图片空状态，并在设置帮助入口以缩略图出现。
- 图库有内容时，角色以“本地 AI 助手”常驻卡片出现在首页；点击可直接切换到语义搜图。
- 首页控制区可折叠，素材工坊标题、导入按钮、排序与网格缩放始终保留；助手卡片支持在两种搜索模式间双向切换。
- 图片详情的 AI 标签助手区域也使用角色头像，建立角色与本地智能功能的固定关联。
- 横向主视觉用于首次启动指引和设置页底部隐私说明卡片。
- 深色模式下优先使用透明底资源；浅底完整画布仅用于卡片或 onboarding。
- 隐私含义用锁与断开的云朵表达，不使用警告红色。
